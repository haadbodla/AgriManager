# ShareHelper Utility - Documentation

**Location:** `utils/ShareHelper.kt`  
**Purpose:** Reusable sharing functionality across all AgriManager modules  
**Created:** December 21, 2025

---

## 📋 **Overview**

`ShareHelper` is a utility class that provides standardized sharing functionality for transaction receipts, ledgers, and reports across all modules in the AgriManager app.

---

## 🎯 **Available Methods**

### **1. shareTransactionReceipt()**
Share individual transaction receipt as formatted text.

**Parameters:**
```kotlin
context: Context          // Android context
employeeName: String      // Employee/Entity name
transactionType: String   // e.g., "Salary Payment", "Advance Given"
amount: Double           // Transaction amount
date: Long              // Transaction timestamp
balance: Double? = null // Optional current balance
```

**Usage Example:**
```kotlin
ShareHelper.shareTransactionReceipt(
    context = context,
    employeeName = "John Doe",
    transactionType = "Salary Payment",
    amount = 25000.0,
    date = System.currentTimeMillis(),
    balance = 21945.0
)
```

**Receipt Format:**
```
━━━━━━━━━━━━━━━━━━━━━━━━
📄 AgriManager Receipt
━━━━━━━━━━━━━━━━━━━━━━━━

Employee: John Doe
Type: Salary Payment
Amount: Rs 25000
Date: 21 Dec 2025, 01:30 AM

Current Balance: Rs 21945

━━━━━━━━━━━━━━━━━━━━━━━━
Generated by AgriManager
```

### **2. shareEmployeeLedger()**
Share complete employee ledger summary.

**Parameters:**
```kotlin

```

**Usage Example:**
```kotlin

    totalSalary = 50000.0,
    totalAdvances = 15000.0,
    balance = 35000.0,
    transactionCount = 12
)
```

---

### **3. shareViaWhatsApp()**
Share directly via WhatsApp app.

**Parameters:**
```kotlin
context: Context
text: String
phoneNumber: String? = null  // Optional: country code + number
```

**Usage Example:**
```kotlin
ShareHelper.shareViaWhatsApp(
    context = context,
    text = "Your receipt text here",
    phoneNumber = "923001234567"  // Format: country code + number
)
```

**Note:** Falls back to regular share if WhatsApp not installed.

### **6. exportAndShareCSV()**
Export data to CSV file and share.

**Parameters:**
```kotlin
context: Context
fileName: String
headers: List<String>
rows: List<List<String>>
```

**Usage Example:**
```kotlin
ShareHelper.exportAndShareCSV(
    context = context,
    fileName = "employee_ledger",
    headers = listOf("Date", "Type", "Amount", "Balance"),
    rows = listOf(
        listOf("21 Dec 2025", "Salary", "25000", "21945"),
        listOf("15 Dec 2025", "Advance", "3000", "7000")
    )
)
```

## 📱 **Required Permissions**

Add to `AndroidManifest.xml` if not already present:

```xml
<!-- For file sharing (CSV, PDF) -->
<provider
    android:name="androidx.core.content.FileProvider"
    android:authorities="${applicationId}.fileprovider"
    android:exported="false"
    android:grantUriPermissions="true">
    <meta-data
        android:name="android.support.FILE_PROVIDER_PATHS"
        android:resource="@xml/file_paths" />
</provider>
```

Create `res/xml/file_paths.xml`:
```xml
<?xml version="1.0" encoding="utf-8"?>
<paths>
    <cache-path name="shared_files" path="." />
</paths>
```

## 📝 **Best Practices**

1. **Always use context from Composable:**
   ```kotlin
   val context = LocalContext.current
   ```

2. **Handle errors gracefully:**
   - ShareHelper includes try-catch blocks
   - Falls back to generic share on errors

3. **Format data before sharing:**
   - Use proper date formatting
   - Round amounts appropriately
   - Include all relevant information

4. **Test on real devices:**
   - Share functionality works differently on emulators
   - Test with actual WhatsApp/SMS apps

5. **Consider user privacy:**
   - Don't include sensitive information
   - Allow users to review before sharing
   - Respect data protection regulations
